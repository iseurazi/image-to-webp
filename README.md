# WebP 변환기 (Image to WebP)

서버 전송 없이 **로컬 브라우저 내부에서만** 정적 비트맵 이미지를 WebP 포맷으로 변환하는 순수 HTML · CSS · JavaScript 웹 애플리케이션입니다.  
외부 라이브러리나 빌드 과정이 없어 `index.html` 파일을 브라우저로 직접 열어(`file://` 포함) 오프라인에서도 바로 사용할 수 있습니다.

---

## 주요 기능

- **모든 정적 비트맵 이미지 → WebP 변환**
  - `JPG / JPEG / JFIF`, `PNG`, `BMP`, `GIF`, `WEBP`, `AVIF`, `ICO`, `TIFF` 등 정적 비트맵 이미지를 지원합니다.
  - `SVG` 등 벡터 파일이나 이미지가 아닌 파일은 자동으로 제외하고 안내 토스트를 표시합니다.
- **투명 배경(Alpha 채널) 유지**
  - 배경을 임의로 채우지 않고 알파 채널을 그대로 유지한 채 WebP로 인코딩합니다.
  - 투명 픽셀이 포함된 이미지는 카드에 `투명` 배지가 표시되며, 체크무늬 배경 위에서 바로 확인할 수 있습니다.
- **여러 이미지 동시 처리**
  - 동시 변환 큐(최대 4개 워커)를 통해 여러 이미지를 빠르게 병렬 처리하며 전체 진행률 바를 표시합니다.
- **편리한 파일 첨부**
  - 브라우저 창 전체 드래그앤 드롭 (폴더 드롭 시 하위 파일 재귀 탐색 지원)
  - 드롭존 클릭을 통한 다중 파일 선택
  - `Ctrl+V` 클립보드 이미지 붙여넣기
- **개별 및 일괄 품질(Quality) 설정**
  - 이미지마다 `1–100%` 범위의 슬라이더 및 숫자 입력으로 변환 품질을 개별 조절할 수 있습니다.
  - 상단 `기본 품질` 및 `전체 적용` 버튼으로 모든 이미지에 동일한 품질을 한 번에 적용할 수 있습니다.
- **원본 / WebP 비교 미리보기 모달**
  - 썸네일 또는 `미리보기` 버튼을 눌러 원본과 변환된 WebP 결과를 나란히 비교할 수 있습니다.
  - `체크무늬`, `밝음`, `어두움` 3가지 배경 전환과 모달 내 실시간 품질 조절을 지원합니다.
- **개별 다운로드 & 일괄 ZIP 다운로드**
  - 변환이 완료된 이미지를 개별 파일(`.webp`)로 바로 저장할 수 있습니다.
  - 외부 압축 라이브러리 없이 구현된 내장 PKZIP(STORE) 빌더를 통해 모든 변환 이미지를 하나의 `.zip` 파일(UTF-8 파일명 및 중복 파일명 자동 번호 부여)로 일괄 다운로드할 수 있습니다.

---

## 파일 구조

```text
image-to-webp/
├── index.html    # 메인 UI, 드롭존, 툴바, 비교 미리보기 모달 마크업
├── style.css     # 반응형 레이아웃 및 체크무늬 배경 스타일
├── app.js        # 파일 필터링, 알파 유지 WebP 변환 큐, PKZIP 아카이브 생성
├── .gitignore    # .vscode/ 등 로컬 설정 제외
└── README.md     # 프로젝트 문서
```

## 사용 방법

1. 저장소를 클론하거나 파일을 내려받은 뒤, `index.html`을 최신 웹 브라우저(Chrome, Edge, Firefox, Safari 등)에서 엽니다.
2. 변환할 이미지를 화면에 드래그앤 드롭하거나 드롭존을 클릭해 파일을 선택합니다.
3. 변환이 완료되면 필요에 따라 각 이미지의 품질(Quality)을 조절하거나 미리보기로 결과를 확인합니다.
4. 각 카드의 **다운로드** 버튼으로 개별 저장하거나, 상단의 **일괄 다운로드 (ZIP)** 버튼으로 한 번에 내려받습니다.

> **참고**: 모든 이미지 디코딩과 인코딩은 브라우저의 `Canvas API`(`canvas.toBlob('image/webp', quality)`)로 처리되므로 이미지가 외부 서버로 전송되지 않습니다.
